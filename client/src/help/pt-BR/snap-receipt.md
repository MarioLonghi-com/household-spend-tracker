O Snap é uma página pequena feita para o celular. Fotografe o comprovante no caixa e ele vai direto para a caixa de entrada de comprovantes, pronto para a correspondência quando o extrato chegar.

## Tirar a foto

1. No celular, abra o app e escolha **Fotografar um comprovante** no menu. Se a sessão tiver expirado, você entra primeiro e volta para ela.
2. Confira a casa no canto superior direito. Se você participa de mais de uma, toque nela para trocar. A página usa a cor dessa casa, para o comprovante não cair na casa errada.
3. Toque no botão grande da câmera e fotografe o comprovante. Para fotos que você já tirou, use o botão logo abaixo, que abre a galeria e deixa escolher várias de uma vez.
4. Cada foto é comprimida no celular e enviada. Quando ela aparecer como já na caixa de entrada, você pode digitar para que foi no campo embaixo dela. Isso fica salvo como as notas do comprovante.

O navegador pode adicionar a página à tela inicial, para ela abrir como um app. O link no canto superior esquerdo volta para o app completo.

## Nada se perde

As fotos ficam no celular até o servidor recebê-las. Sem sinal, tire a foto mesmo assim: ela espera na fila e é enviada na próxima vez que você abrir o Snap com conexão. Uma foto que não pôde ser enviada mostra um botão para tentar de novo.

## Localização

O botão de localização fica desligado até você ligá-lo. Desligado, a foto registra só o que a câmera gravou nela, o que pode já incluir onde foi tirada.

Ligado, cada foto enviada registra também onde o celular está naquele momento, e isso só é usado quando a foto não traz localização própria. Vai para o servidor desta casa e para nenhum outro lugar. Como é a posição atual do celular, uma foto da galeria tirada em outro lugar recebe o lugar de onde você a envia. A escolha fica lembrada naquele celular.

Os navegadores só oferecem localização em conexão segura (https); numa conexão comum, o botão fica indisponível e a página explica por quê.

## Depois

Os comprovantes do Snap esperam na tela [Comprovantes](screen:receipts). Para colocar um na transação dele, veja [Anexar um comprovante a uma transação](help:attach-receipt).
